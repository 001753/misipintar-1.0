ARSITEKTUR INTI — WAJIB DIPATUHI SETIAP SAAT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. MULTI-TENANT: Jangkar data adalah FamilySpace (Tenant ID). SETIAP query Prisma WAJIB menyertakan filter `familySpaceId` yang diambil dari SESSION SERVER — BUKAN dari parameter klien/URL.
2. ZERO CLIENT-SIDE MATH: Semua kalkulasi keuangan (bunga, pajak, denda, saldo) HANYA di server. Tidak ada kalkulasi angka finansial di browser/komponen React.
3. SERVER ACTIONS ONLY untuk mutasi data — tidak ada API route untuk operasi yang menyentuh saldo/transaksi.
4. ATOMICITY: Setiap operasi yang menyentuh saldo menggunakan `prisma.$transaction()` — tidak ada operasi saldo tanpa transaksi database.
5. AUDIT LOG PERMANEN: Setiap aksi superadmin (ubah harga, limit, force expire, refund) WAJIB menulis ke tabel `AdminAuditLog` di database — BUKAN console.log.
6. NO E-MONEY: Platform ini adalah sistem pencatatan edukatif (virtual ledger), BUKAN penyelenggara jasa pembayaran. Payment gateway Midtrans hanya untuk biaya LANGGANAN PLATFORM — bukan transfer saldo anak.

ATURAN KEAMANAN — TIDAK BOLEH DIKOMPROMIKAN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- Rate limiting login: MAX 5 percobaan gagal dalam 15 menit per identifier → blokir. Gunakan tabel `LoginAttempt` di DB + Redis counter.
- Password anak: minimal 6 karakter, tidak boleh sama dengan username, tidak boleh kosong, selalu di-hash bcrypt.
- Cookie secure: isSecureContext() hanya percaya header x-forwarded-proto jika env `TRUST_PROXY=true` — default TIDAK percaya header klien.
- Webhook Midtrans: WAJIB validasi signature SHA-512 server-to-server. JANGAN aktivasi subscription dari callback client-side (Snap.js onSuccess).
- Idempotency webhook: Gunakan `Subscription.invoiceId` UNIQUE constraint di database sebagai jaring pengaman race condition — jangan hanya mengandalkan pengecekan status di kode.
- Cross-tenant: DILARANG KERAS query tanpa filter `familySpaceId`. Pelanggaran = data leakage antar keluarga.

- Plan (konfigurasi paket: STARTER/PRO/EDUCATOR/SCHOOL)
- Invoice (tagihan, relasi ke Subscription)
- PaymentLog (log detail pembayaran)
- Notification (inbox notifikasi in-app)
- LoginAttempt (audit percobaan login — BARU v4.1)
- AdminAuditLog (audit permanen aksi superadmin — WAJIB v4.1)
- AppConfig (konfigurasi global, dikelola SuperAdmin)
