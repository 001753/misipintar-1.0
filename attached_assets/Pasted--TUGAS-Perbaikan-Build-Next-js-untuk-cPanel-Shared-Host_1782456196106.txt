## FASE 2A: PERBAIKAN `package.json`

Lakukan EMPAT perubahan ini, tidak lebih, tidak kurang:

### Perubahan 1 — Perbaiki versi Next.js
CARI:
  "next": "^16.2.9"
GANTI DENGAN:
  "next": "15.3.4"

ALASAN: Next.js 16 belum dirilis. `^16.2.9` menyebabkan
npm menginstall versi lain secara diam-diam → mismatch runtime.

### Perubahan 2 — Selaraskan eslint-config-next
CARI:
  "eslint-config-next": "16.2.9"
GANTI DENGAN:
  "eslint-config-next": "15.3.4"

ALASAN: Versi harus identik dengan versi Next.js yang diinstall.

### Perubahan 3 — Hapus --webpack dari script "build"
CARI (kurang lebih):
  "build": "NEXT_BUILD=1 ... next build --webpack"
GANTI DENGAN:
  "build": "NEXT_BUILD=1 NEXT_TELEMETRY_DISABLED=1 RAYON_NUM_THREADS=1 TOKIO_WORKER_THREADS=1 UV_THREADPOOL_SIZE=1 next build"

ALASAN: Flag `--webpack` dihapus dari Next.js sejak versi 15.
Meneruskan flag tidak dikenal ke Rust SWC worker → SIGABRT deterministik.

### Perubahan 4 — Hapus NODE_OPTIONS dari semua script build
Di script "build", "build:debug", "build:prod", "build:cpanel":
HAPUS bagian: NODE_OPTIONS='--max-old-space-size=...'

ALASAN: NODE_OPTIONS sudah diset oleh deploy.sh dengan logika
retry otomatis. Jika keduanya set → dua flag --max-old-space-size
dalam satu string → undefined behavior di V8 → abort.

Script "start" dan "dev" TIDAK DIUBAH.

## FASE 3: VERIFIKASI & BUILD TEST

Setelah perubahan package.json, jalankan urutan ini:

### Langkah 1 — Reinstall dependencies bersih
```bash
rm -rf node_modules package-lock.json
npm install
```

### Langkah 2 — Konfirmasi versi terinstall
```bash
node -e "const p=require('./node_modules/next/package.json'); console.log(p.version)"
```
Output HARUS: 15.3.4
Jika bukan 15.3.4, BERHENTI dan laporkan.

### Langkah 3 — Jalankan build test
```bash
NEXT_BUILD=1 NEXT_TELEMETRY_DISABLED=1 RAYON_NUM_THREADS=1 \
TOKIO_WORKER_THREADS=1 UV_THREADPOOL_SIZE=1 \
NODE_OPTIONS='--max-old-space-size=1024' next build
```

### Langkah 4 — Verifikasi output standalone
```bash
ls -lh .next/standalone/server.js
```
File harus ada dan berukuran > 10KB.
Jika tidak ada, laporkan error build lengkap dari atas.

## FORMAT LAPORAN AKHIR

Setelah build sukses, buat laporan dengan format ini:

---
STATUS: [SUKSES / GAGAL]

FILE DIUBAH:
- package.json: [daftar 4 perubahan dengan nilai before/after]

VERSI NEXT.JS TERINSTALL: [versi aktual]

OUTPUT BUILD:
- .next/standalone/server.js: [ukuran file]
- .next/static/: [ada/tidak]

PERINTAH UNTUK SSH cPANEL:
```bash
rm -rf node_modules package-lock.json
npm install
npm run build
pkill -u smknwon2 node || true
touch tmp/restart.txt
```
---

Jika build GAGAL, sertakan:
- 50 baris terakhir output error
- Hipotesis penyebab tambahan
- Langkah perbaikan selanjutnya
