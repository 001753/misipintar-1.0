Diagnosis: Browser meminta /_next/static/... tapi file tidak ada di server. Ini karena Next.js standalone output tidak otomatis menyertakan static assets.

Langkah perbaikan di cPanel (sekarang):

Opsi A — Upload ulang dari Replit (direkomendasikan)

Lalu upload ulang seluruh .next/standalone/ ke cPanel.

Opsi B — Copy langsung di cPanel SSH (lebih cepat, tidak perlu upload ulang)

# Di cPanel SSH, dari folder source code (misipintar-1.0):
cp -r .next/static/ public_html/misipintar/.next/static/
cp -r public/ public_html/misipintar/public/
