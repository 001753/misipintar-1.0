Langkah yang benar
1. Deploy versi aplikasi terbaru

deploy build terbaru ke server cPanel. Setelah deploy selesai, route berikut harus tersedia:

Jika menggunakan Replit Deployments, publish project terlebih dahulu. Gunakan URL production yang diberikan Replit, misalnya:

https://nama-project.replit.app/api/webhooks/doku

Gunakan URL *.replit.app, bukan *.replit.dev.

2. Tes apakah route sudah aktif
Jalankan:

curl -i -X POST \
  https://mp.jobenapp.cloud/api/webhooks/doku \
  -H "Content-Type: application/json" \
  --data '{}'

Jika route sudah aktif, respons yang diharapkan adalah kira-kira:

HTTP/1.1 403
{"message":"Invalid signature"}

Itu justru berarti route sudah benar dan bisa diakses. Signature invalid wajar karena request tersebut bukan notification DOKU yang ditandatangani.

Kalau hasilnya:

404 Not Found

berarti aplikasi terbaru belum aktif di domain tersebut.
