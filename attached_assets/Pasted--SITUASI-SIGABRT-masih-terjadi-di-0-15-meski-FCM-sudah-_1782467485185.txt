## FASE 2 — DUA PERBAIKAN INTI (tidak ada yang lain)

### Fix UTAMA: next.config.ts — matikan static generation dari akar

Buka `next.config.ts`. GANTI SELURUH objek `nextConfig` dengan versi
ini (pertahankan semua config yang sudah ada, tambahkan 3 baris baru):

```typescript
const nextConfig: NextConfig = {
  output: "standalone",
  
  // === TAMBAHAN BARU — paksa semua route jadi dynamic dari level config ===
  // Ini override per-page exports dan berlaku untuk SEMUA versi Next.js
  staticPageGenerationTimeout: 1,
  
  // experimental.isrMemoryCacheSize: 0 → matikan ISR cache
  // experimental.workerThreads: false → paksa single-process, no fork
  // Keduanya mencegah spawn worker process baru di cPanel ulimit ketat
  
  devIndicators: false,
  typescript: { ignoreBuildErrors: true },
  // ... (sisa config tidak diubah)
  experimental: {
    cpus: 1,
    workerThreads: false,       // ← TAMBAH INI
    isrMemoryCacheSize: 0,      // ← TAMBAH INI  
    serverActions: { allowedOrigins: ["*"] },
  },
  // ... (sisa config tidak diubah, termasuk headers, images, webpack, dll)
};
```

PENTING: Hanya tambahkan `workerThreads: false` dan `isrMemoryCacheSize: 0`
ke dalam `experimental` yang sudah ada. Jangan hapus config lainnya.

### Fix PENDUKUNG: deploy.sh — pastikan NEXT_BUILD dikirim ke worker

Cari baris di deploy.sh yang menjalankan `next build` (sekitar baris 250).
Pastikan command build memiliki `NEXT_BUILD=1` di depannya.

Jika command saat ini seperti:
```bash
NODE_OPTIONS="..." next build
```

Ganti menjadi:
```bash
NEXT_BUILD=1 NODE_OPTIONS="..." next build
```

Jika `NEXT_BUILD=1` sudah ada, lewati fix ini.

## FASE 3 — VERIFIKASI KRITIS DI REPLIT

```bash
# Test build dengan flag lengkap persis seperti yang dipakai deploy.sh
NEXT_BUILD=1 NEXT_TELEMETRY_DISABLED=1 RAYON_NUM_THREADS=1 \
TOKIO_WORKER_THREADS=1 UV_THREADPOOL_SIZE=1 \
NODE_OPTIONS='--max-old-space-size=768' \
npx next build 2>&1 | grep -E "static pages|worker|SIGABRT|error|Error" | head -20
```

KRITERIA SUKSES — salah satu dari ini harus terpenuhi:
1. `Generating static pages (0/0)` — ideal, nol halaman statis
2. Fase "Generating static pages" tidak muncul sama sekali — berarti
   dilewati karena workerThreads: false
3. Build selesai tanpa kata "SIGABRT" atau "worker exited"

Jika masih ada (0/N) dengan N > 0, jalankan:
```bash
grep -r "generateStaticParams\|getStaticProps\|getStaticPaths" \
  src/ --include="*.tsx" -l
```
Dan hapus semua fungsi tersebut dari file yang ditemukan.
