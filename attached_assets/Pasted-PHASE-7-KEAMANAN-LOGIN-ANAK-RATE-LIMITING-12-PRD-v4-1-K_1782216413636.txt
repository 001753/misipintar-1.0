TUGAS [7.1] — LOGIN GUARD (RATE LIMITING)
Buat `src/lib/auth/loginGuard.ts` PERSIS sesuai PRD §12.2:

```typescript
const MAX_ATTEMPTS = 5
const WINDOW_MINUTES = 15

export async function checkLoginRateLimit(
  identifier: string,
  ipAddress: string
): Promise<void> {
  const since = new Date(Date.now() - WINDOW_MINUTES * 60 * 1000)
  
  const failedCount = await prisma.loginAttempt.count({
    where: {
      identifier,
      success: false,
      createdAt: { gte: since },
    },
  })
  
  if (failedCount >= MAX_ATTEMPTS) {
    // JANGAN bedakan pesan dengan "password salah" — cegah enumeration attack
    throw new Error('RATE_LIMITED')
  }
}

export async function recordLoginAttempt(
  identifier: string,
  ipAddress: string,
  success: boolean
): Promise<void> {
  await prisma.loginAttempt.create({
    data: { identifier, ipAddress, success },
  })
}
```

TUGAS [7.2] — INTEGRASI KE AUTH HANDLER
Update NextAuth credentials providers:

Untuk Parent login (email):
1. Panggil checkLoginRateLimit(email, ipAddress) — jika throw RATE_LIMITED, return null dengan pesan "Terlalu banyak percobaan, coba lagi dalam 15 menit"
2. Verifikasi password dengan bcrypt.compare
3. Panggil recordLoginAttempt(email, ip, berhasil/tidak)
4. Jika berhasil → return user session
5. Jika gagal → return null

Untuk Child login (spaceCode + username):
1. Identifier = `${spaceCode}:${username}` (gabungkan untuk rate limit)
2. Panggil checkLoginRateLimit(identifier, ipAddress)
3. Cari FamilySpace by spaceCode, lalu Child by username dalam space tersebut
4. Verifikasi password dengan bcrypt.compare
5. Panggil recordLoginAttempt(identifier, ip, berhasil/tidak)

TUGAS [7.3] — PASSWORD VALIDATION (ZOD SCHEMA)
Buat `src/lib/auth/passwordPolicy.ts`:
```typescript
import { z } from 'zod'

export const childPasswordSchema = z
  .string()
  .min(6, 'Password minimal 6 karakter')
  .refine((val) => val.trim().length > 0, 'Password tidak boleh kosong')

export function validateChildPassword(password: string, username: string): void {
  childPasswordSchema.parse(password)
  if (password.toLowerCase() === username.toLowerCase()) {
    throw new Error('Password tidak boleh sama dengan username')
  }
}

export const parentPasswordSchema = z
  .string()
  .min(8, 'Password minimal 8 karakter')
  .regex(/[A-Z]/, 'Harus ada huruf kapital')
  .regex(/[0-9]/, 'Harus ada angka')
```

Terapkan validasi ini di:
- createChild (password awal anak)
- changeChildPassword
- Register parent baru

TUGAS [7.4] — SECURE CONTEXT (§12.4 PRD v4.1)
Buat/update `src/lib/utils/env.ts`:
```typescript
export function isSecureContext(headersList?: Headers): boolean {
  // Pertama: cek APP_URL dari env (paling aman)
  if (process.env.APP_URL?.startsWith('https://')) return true
  
  // Kedua: percaya proxy header HANYA jika TRUST_PROXY=true
  if (process.env.TRUST_PROXY === 'true' && headersList) {
    return headersList.get('x-forwarded-proto') === 'https'
  }
  
  // Default: tidak percaya — aman untuk development
  return false
}
```
Terapkan ini di konfigurasi cookie session NextAuth.
