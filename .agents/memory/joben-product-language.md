---
name: JOBEN product language
description: The user’s standing language requirement for JOBEN’s product UI and user-facing text.
---

Use clear, easy-to-understand Bahasa Indonesia throughout the JOBEN system. A few familiar English terms are acceptable.

**Why:** the user explicitly set this language requirement while defining the JOBEN PRD.

**How to apply:** write user-facing labels, help text, validation, notifications, and empty/error states in simple Indonesian; keep any English terms familiar and consistent.
